# 报表与字段授权

项目可见不代表报表可查。MCP 对普通报表、模板及 ODS 每次重新检查当前用户的实时角色、菜单和字段，再校验真实维度候选。不要以之前会话的项目列表或字段结果当作长期授权，也不要要求用户指定角色、菜单或其他身份。

- `REPORT_NOT_ALLOWED`：没有目标报表菜单，停止，不换接口绕过。
- `FIELD_NOT_ALLOWED`：显式维度、指标、周期、筛选或排序未授权。整次停止，不能删字段后声称完成。
- `PERMISSION_VALIDATION_UNAVAILABLE`：无法确认权限，可能是权限接口失败、结构异常或缺少参数与字段映射；不能宣称已经证明无权限。读取当前契约 `queryCapabilities.authorization.unmappedParameters` 了解具体不可用参数。
- `PARAM_NOT_ALLOWED` 与 `PARAM_VALIDATION_UNAVAILABLE` 仍分别表示候选不允许和候选无法验证。

模板继承列和默认指标可以按权限裁剪；说明 `accessControl.prunedFields`，以实际返回为准。缺失、null、零分别保留，不能补回被裁剪字段。返回过滤也覆盖原始汇总、嵌套指标、ODS 汇总和字段说明，未知扩展可能不返回，不能猜造。

角色、菜单、字段请求也占用串行工作流和至少一秒间隔。合格率两张表分别鉴权；任一失败，不宣称双表查询成功。模板后续页需保留权限参与后的查询指纹，权限变化停止拼接。

服务端独立校验实时菜单，不信任登录缓存菜单；字段授权仍依赖 BI 当前用户字段接口。权限变更后需重新验证；无法确认授权时停止查询。
