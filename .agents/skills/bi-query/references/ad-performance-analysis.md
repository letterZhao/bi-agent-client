# 投放经营分析

适用于海外 App 的广告获客、订阅、续订及退款分析。先完成入口 SKILL.md
规定的 BI 取数与校验；本文件不替代工具契约，不提供新增接口或写入授权。

## 确定分析条件

确认项目、安装同期群（cohort）日期、查询时区、观察截止时间和用户关心的目标。
缺少完成查询所必需的条件时先追问。用户未提供回本目标时，可以先比较历史及同龄
cohort，注明目标未提供及其影响；不能把通用行业值当作该项目已确认的关停线。

## 统一口径与成熟度

- 区分安装 cohort 累计收入与自然日财务收入，分别记录获客日期和观察截止时间。
- 固定日龄 ROI 只比较已经完整成熟且刷新完成的 cohort。按契约区分自然日与 24H
  口径，结合查询时区、获客窗口和数据刷新确认日龄。包含多个获客日期时，逐日判断
  或仅比较共同成熟的部分，说明排除范围；不能把整个区间视为同龄。
- 昨日安装的用户尚未完整成熟到 D7，即使 D7 字段非空，也不能据此判断是否关停。
  刷新时间或日龄定义缺失时披露成熟度未验证，不猜刷新时间或将字段有值作为证明。
- 区分累计 ROI、固定日龄 ROI、广告 ROI、订阅 ROI 和总 ROI。使用
  [同期群指标映射](cohort-metrics.md) 及当前契约的真实选择值和返回路径；不能用累计值
  替代指定日龄。比例展示遵循各报表契约，不对 IAA 与 IAP 的所有比率统一乘 100。
- 有足够渠道数据时分别展示付费渠道和自然量；不把自然量收入直接计为广告增量收入。
- 核对收入分成与退款口径，验证前不将回收比例称为净利润。回收曲线未到目标时，只能
  说明在已观测窗口内尚未回本；没有完整长期数据时，不断言生命周期盈利或给出确定回本日。
- 沿用入口规则处理 sum、分页、null、缺失和被裁剪字段。当前页不能作为全量排名或
  全量预算分配依据。跨组比例使用可验证的分子/分母，不简单平均各行百分数；缺少
  分母时不强算。对四舍五入后的 ROI 加权时标注近似值，金额计算保留十进制精度。

## 诊断与建议

按渠道、国家、系列、广告组、素材逐层定位，只选择当前契约支持且实际取得数据的粒度。
同国家、同原系列、同安装窗口的素材比较优先；仍需披露受众、分流、样本量和投放时间
等混杂因素。某层不可用时说明缺口，不把其他层级的字段冒充该层级。

试用率高不等于付费或回收好；结合实际可得的转付费、取消、续订及退款判断收入质量。
逐项核对分子、分母、观察时长和累计/固定日龄定义，不将取消率与退款率相互替代。
缺少订阅或续订数据时限定结论，不推算未返回的转化或收入。

将建议标为放量测试、优化测试、观察或暂停建议，给出依据、观察窗口、置信度及其理由、
复查条件和未验证项。置信度使用证据充分程度的定性描述，不虚构统计概率。
暂停建议需同时说明重启条件。阈值引用用户确认的目标或清晰标注的相对比较依据；
缺少成熟可比数据时优先补数或观察，不给出确定性关停结论。
具体出价或预算幅度若有提出，应标为试验起点，不能说成数据证明的最优幅度。

只有归因收入与聚合相关性时，不声称证明广告增量或因果；可提出需要对照实验的假设。
没有素材内容、平台频次、搜索词或实验数据时，不断言素材疲劳、文案错误、某个搜索词
低效或某段视频需要修改。

## 保留可检索的对象身份

每项建议至少保留：

- 对象层级：channel / campaign / adgroup / creative。
- 对应原始 ID 与原始名称；未返回的字段标明未提供，不猜造 ID 或以其他层级补齐。
- 项目、渠道、国家（实际已查询时）、日期、时区与刷新时间（未返回则注明未提供）。
- 用于复核的报表、指标字段、筛选及已取分页范围；未知网页检索方式标注未验证。
- 建议动作、证据、观察窗口、复查条件，以及暂停后的重启条件（适用时）。

可以另加中文标题，但不能用标题替代原始名称。campaignName 的值不能作为 creativeName
展示，也不能要求用户填入素材名称。BI 的 creativeName 是否对应平台视频、图片、关键词等，
须核对映射后再判断。

## 输出与权限

按用户指定格式输出；本工作区要求可预览 HTML，当前界面无法直接渲染时生成独立 HTML
文件并提供链接。每条结论关联实际响应、查询参数或已核实文档，标明数据来源、验证方法
和未验证项。模拟数据只用于行为验收，必须标为模拟，不能作为真实经营结论。

本模块只分析并提出建议，不执行预算调整、暂停或重启，不扩大已有工具权限。
